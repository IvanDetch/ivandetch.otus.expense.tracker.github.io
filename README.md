
# OTUS Expense Tracker (React + TypeScript)

Готовое приложение для учета доходов/расходов под REST API из архива `otus-rest-server-main.zip`.

## Технологические решения (и почему)

- **Стили: Sass Modules + CSS variables** — нулевой рантайм, быстрая отрисовка, изоляция стилей, простая поддержка темной темы через `data-theme` и CSS-переменные. Для pet/диплома быстрее и стабильнее, чем CSS-in-JS.
- **Состояние: Redux Toolkit + RTK Query (Thunk)** — меньше бойлерплейта, кэширование/рефетч из коробки, `prepareHeaders` для токена. Для нашего CRUD это проще и надежнее, чем Saga. Саги нужны в первую очередь для сложных оркестраций.
- **API: REST** — предоставлен готовый сервер (`http://19429ba06ff2.vps.myjino.ru/api`). RTK Query легко работает с query params (`filters` в JSON). Архитектура позволяет заменить на GraphQL слоем сервисов.
- **Формы: react-hook-form + zod** — легкий рантайм, декларативная валидация и типобезопасность.
- **Маршрутизация: React Router v6** — защищенные роуты, редиректы.
- **i18n: i18next** — опциональная смена языка (EN/RU).
- **Тесты: Vitest + Testing Library** — быстрые unit/компонентные тесты.
- **Бандлер: Vite** — быстро и просто.

## Запуск

```bash
# 1) установить зависимости
npm i

# 2) указать API сервера (по умолчанию уже задан)
echo VITE_API_URL=http://19429ba06ff2.vps.myjino.ru/api > .env

# 3) dev
npm run dev

# 4) prod
npm run build && npm run preview
```

## Структура API (важное)

Сервер ожидает фильтры в query param `filters`, где значение — **JSON**. Например для операций:
```http
GET /operations?filters={{"pagination":{{"pageNumber":1,"pageSize":10}},"type":"Profit","sorting":{{"type":"DESC","field":"date"}}}}
```
Создание операции:
```http
POST /operations
{{
  "name": "Salary", "amount": 1000, "date": "2023-09-19T10:37:16.389+00:00",
  "type": "Profit", "categoryId": "..."
}}
```
